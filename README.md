
Aplicación frontend desarrollada con **SAP UI5** en BAS que permite visualizar un perfil profesional completo (CV).  
La aplicación consume servicios expuestos por un **backend CAP (Node.js)** desplegado en **SAP BTP Cloud Foundry**.

Este proyecto forma parte de una arquitectura full-stack SAP orientada a demostrar el uso de **SAP UI5 + CAP + BTP** en una aplicación real.

---

## Arquitectura

SAP UI5 (Frontend)  
↓  
SAP Approuter  
↓  
CAP Node.js Backend  
↓  
PostgreSQL (SAP BTP)

El frontend consume datos del backend mediante endpoints REST expuestos por los servicios CAP.

---

## Tecnologías utilizadas

- SAP UI5
- SAP Fiori Tools
- SAP Business Application Studio
- SAP Approuter
- CAP (Cloud Application Programming Model)
- Node.js
- PostgreSQL
- SAP BTP Cloud Foundry
